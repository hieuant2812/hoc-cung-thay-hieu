Tự học

Luyện tập theo chương, dạng, mức độ ngay trên điện thoại — chấm ngay, có lời giải. Sổ tay kiến thức theo từng bài: tóm tắt lí thuyết, dạng bài có giải mẫu, sơ đồ tư duy.

1. Chọn bộ câu hỏi

Đang tải…
Có file bộ luyện tập thầy cô gửi?
Bộ luyện tập là một tập câu riêng thầy chọn để học sinh tự luyện (có đáp án, lời giải). Vì sẽ đưa lên mạng, thầy nên chọn câu không dùng cho kiểm tra: tích “Bỏ các câu đã dùng trong đề kiểm tra” hoặc chọn mức Biết – Hiểu.

1. Chọn câu từ ngân hàng trên máy

2. Xuất bộ luyện tập

  1. Bấm nút trên: máy tải về 2 file — file bộ câu (LT_….json) và index.json (danh sách các bộ).
  2. Trên github.com, mở thư mục data → luyentap (lần đầu: Add file → Upload files, kéo 2 file vào và đổi đường dẫn thành data/luyentap/).
  3. Tải cả 2 file lên thư mục đó rồi Commit. Học sinh mở trang Tự học là thấy bộ mới.
  4. Cũng có thể gửi thẳng file LT_….json qua Zalo; học sinh bấm “Mở file .json”.
